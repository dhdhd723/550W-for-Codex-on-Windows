# 550W 0.3.0

- `550W简洁版.zip`：约 4 秒 SVG 标识绘制，无音频，包内不含 MP3。
- `550W完整版.zip`：约 16 秒完整终端与节点动画，当前 MP3 从片头开始播放，最终为 `SYSTEM IS REWRITTEN`。
- 两版使用同一原版样式，配色与点击/Esc 保持，各自保存偏好。
- 修复标识最后一秒红色 0 的光晕造成轮廓粘连，保留原 SVG 轮廓和绘制时序。
- 不含开发者的本机配置、私测日志、聊天/桌面截图和原始本机路径记录。

原动画和音频公开再发布许可未独立确认，新增代码 MIT 不覆盖这些素材及第三方运行时；署名和范围见随包通知。
