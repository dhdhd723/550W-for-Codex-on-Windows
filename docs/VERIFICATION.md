# 验证范围

2026-10-11 在 Windows x64、Python 3.12.14、PySide6 6.11.2 下验证。0.3.0 的核心与音频结果保留；0.3.1 关闭红色 0 的完成态模糊光晕；0.3.2 再修正最终横牌宽度。以下结果按实际执行范围记录，原始日志和桌面截图只保留在开发工作目录，不随源码或发行包上传。

## 已验证

- 36 项核心、版本策略和真实 Qt WebEngine 测试全部通过。涵盖原动画时间线、550W 标识、最终横牌、四种配色、跳过、等待、退出与异常处理，以及 MP3 解码、自动播放、停声和音频故障处理。
- 0.3.1 修复后，8 项受影响动画测试重新通过。新增严格像素回归在真实 Qt 渲染的 DPR 1.0、1.25、2.0 下各通过，覆盖实际 3.3、3.7、4.0 秒及退出后 50–620ms；红色 0 开口保持背景亮度，明亮轮廓不扩张。原 SVG 路径和原版 CSS 的静态保真检查通过。这些 DPR 使用 Qt 缩放参数取得，没有切换 Windows 显示设置，也没有据此宣称混合 DPI 硬件验证成功。
- 0.3.2 的完整动画回归重新通过，另外七项原动画用例通过。新增最终横牌的实际文字边界检查：一次完整播放后，1280、1920、700、640 四种逻辑视口均完整显示 `SYSTEM IS REWRITTEN`，文字没有越过横牌或视口边界。Qt 窗口固定逻辑尺寸不等同于物理屏幕热插拔测试。
- 简洁版原生静音，约 4 秒绘制标识，不请求音频资源。完整版保持完整终端和 47 个节点动画，音频从片头开始，最终横牌为 `SYSTEM IS REWRITTEN`。
- 0.3.1 两个中文文件名的实际 EXE 预览完成并退出，进程总耗时分别约 6.2 秒和 18.4 秒，含启动资源加载和淡出；完整版产生音频播放、结束和停止事件。
- 0.3.1 实际简洁版和完整版进入已经运行的官方窗口均通过。完整版重复点击只保留一个实例、Esc 停声并进入官方窗口、关闭动画后直接进入官方窗口也通过。没有结束官方应用或后台进程。
- 0.3.0 简洁版曾在一次后台自动测试中遇到 Windows 拒绝聚焦：官方窗口已响应，启动器给出明确提示并安全关闭。该次结果不能记为自动聚焦成功；0.3.1 本轮成功不代表 Windows 的后台聚焦限制已消失。
- 两版快捷方式在 Windows PowerShell 下实际创建：中文名称、EXE 目标、工作目录和图标正确。可同时存在；重复创建不覆盖，显式选择错误版本会报错。测试生成的快捷方式已删除，发行包不带本机 `.lnk`。
- 两份 ZIP 均通过 CRC、成员字节及路径检查。简洁版不含 MP3；完整版 MP3 长度约 13.035 秒、元数据标签已移除。
- 公开源码和打包代码未发现真实本机路径、私人邮箱或凭据。检查覆盖每个 EXE/PYZ 的 5,839 个代码对象及基础库 2,648 个对象；自有源码文件名均为相对路径。保留的是公开作者署名和第三方许可信息。

## 仍需实机验证

官方应用完全关闭后的冷启动、物理多显示器热插拔、混合 DPI 屏幕切换，以及物理扬声器可听性。自动测试确认媒体解码和播放状态，不代表实际扬声器音量；音频内容未逐字转录。

这两个启动器 EXE 当前没有代码签名。Windows 下载检查可能显示未识别发布者；可校验发行页的 SHA-256 或从源码自行构建。官方客户端的文件与签名没有改动。

窗口就绪采用 Win32 可响应主窗口检查，不等于登录、联网、后台 app-server 或工作区加载完成。Windows 可能限制后台聚焦；启动器会提示用户点击官方任务栏图标。程序未使用输入注入或修改官方文件绕过该限制。
